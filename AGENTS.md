# AGENTS.md

## Что это за репо
Общий репо для общих лабораторных. Внутри лежат только авторские версии работ — это шаблоны/отправные точки, а не готовые к сдаче отчёты.

## Структура
- `src/<предмет>/<лаба>/` — работа автора (отчёт + артефакты).
- `csae-report/` — сабмодуль, эталон на LaTeX. Не трогаем.
- `report_template_typst/` — сабмодуль, Typst-шаблон отчёта.

## Правила
- Чужие отчёты в репе не правим. Свои правки держим локально и не коммитим.
- Отчёты пишем в `.md` или `.txt`, каждый форматирует под себя.
- В `main` напрямую не пушим — только через PR.
- Ветка на человека (например `leontevskii`), не на лабу. В ней все его работы.
- Мерж обычный, не squash. Ветку после мержа не удаляем, работаем в ней дальше.
- Пишем, как проходила защита, — чтобы у сокомандников не было сюрпризов.

## Работа с git
```
git switch main && git pull          # свежий main
git switch -c <имя>                  # своя ветка (один раз)
# ... работа, коммит ...
git push origin <имя>                # PR открываем на GitHub
# перед новой лабой:
git switch main && git pull
git switch <имя> && git merge main
```

## Сборка Typst-отчёта
```
cd report_template_typst
make report        # или: typst compile main.typ
```
- Вход: `main.typ`, логика шаблона — `lib.typ`, картинки — `images/`, библиография — `references.yml`.
- Собранный `main.pdf` и прочие `*.pdf` не коммитим.
